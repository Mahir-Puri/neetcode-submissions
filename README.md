## 🧠 My Problem-Solving Approach

For each problem, I try to follow these steps:

1. **Understand the problem** — Clarify requirements, constraints, and edge cases.
2. **Start with brute force** — Find a simple working solution before optimizing.
3. **Identify the pattern** — Decide whether BFS, DFS, two pointers, DP, or another algorithm fits.
4. **Optimize** — Improve time and space complexity where possible.
5. **Dry run the solution** — Walk through examples and edge cases.
6. **Analyze complexity** — Understand why the solution is efficient.

I'm focusing on being able to explain *why* my code works, not just getting an accepted submission.
